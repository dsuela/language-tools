# Symfony LSP for VS Code

Symfony LSP adds Symfony-aware completion, hover, navigation, references,
diagnostics and code actions while working alongside a general PHP language
server.

Platform-specific release packages contain the language server and Tree-sitter
sidecar. The extension also configures Symfony project settings, workspace
trust, Twig file associations, index status and index management commands.

Installation, configuration and supported integrations are covered in the
[Symfony LSP documentation](https://github.com/symfony/language-tools).
